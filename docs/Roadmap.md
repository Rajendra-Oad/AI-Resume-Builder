# Roadmap

The roadmap follows the architecture-first plan defined in
[Project Foundation Setup](01_Project_Foundation_Setup.md) and the implementation
status tracked in [Implementation Gap Audit](01-07_Implementation_Gap_Audit.md).

## Phase 1

- Repository foundation and documentation.
- Authentication and user profile basics.
- Resume CRUD and structured resume data.
- Database migrations and local development workflow.

## Phase 2

- Resume builder editing experience.
- Templates and preview/export alignment.
- AI generation and improvement flows.
- ATS analysis and job matching workflows.

## Phase 3

- Subscriptions, entitlements, and billing boundaries.
- Admin dashboard and moderation tools.
- Analytics, notifications, and audit reporting.
- Collaboration, sharing, and advanced version history.

Use the audit documents for current implementation gaps rather than treating this
page as a release checklist.
